## 497 IDML 对比卡死 — 根因定位与优化方案（2026-08-06 下午）
- 现象：497级 IDML（497有图.idml 2.38MB / 497导出_WD注入.idml 4.1MB，均 63 万字级）对比卡死
- 复现数据：解析 A 5.0s + B 11.7s + diff 131.1s = 总 147.7s > 前端 COMPARE_TIMEOUT_MS 120s → 前端先超时断开
- 根因①：diff_engine 全量 DMP diff_main（Diff_Timeout=0 无超时）在 63 万字/D=50181 密集差异下 O(n·m) 退化，单 diff_main 占 129.3s（99%）
- 根因②：compare 是 async def 但同步调用 diff → 阻塞 uvicorn 事件循环 → 期间 health/autosave 全挂（整个后端假死）
- 根因③：DMP 默认 1s 超时被设 0；若设默认值会"1s 中止降级为粗粒度"（实测 4 ops），不可取
- 已验证方案（v7，重构一致性 A/B 均 True）：段落级 LCS（保留 U+2029 的 split_keep + md5 + DP 矩阵 0.78s）+ 替换组限长策略（≤4096 字符组内字符级 DMP ×130，>4096 段落级粗粒度 DEL+ADD ×125）→ diff 3.7s，全链路 ~21s，提速 35 倍
- 反证排除：锚点分块串行（重写区 DMP 仍慢，15min+）、段落序列 DMP（hash 序列 bisect 退化 8min+）
- 配套修复：main.py async→def（丢线程池防阻塞）；api.ts 120s→300s；DMP Diff_Timeout 全局 30s 兜底
- 497 两版差异本质：重排重写型（B 1322 段 vs A 1640 段，del 17084/add 7535），125 处重写区段落级展示语义合理
- 临时基准脚本残留 scripts/_bench*.py（safe-delete 拦截未删，无副作用）
