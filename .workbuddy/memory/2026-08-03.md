# 2026-08-03 工作日志

## rebuildDiffLayer 错位 Bug 分析与修复方案

### 问题
- 用户在编辑模式删除含原始 diff 装饰的文本时，字符乱序 + 丢失
- 根因：`rebuildDiffLayer`（CodeMirrorDiff.vue L121-178）长度锁步算法错误
- phantom 段（del/mod-old）的 `text.length` 被计入 baseline 消费预算（need），但 phantom 文本不在 baseline 中 → 游标错位

### 修复方案
- 抛弃长度锁步，改为预计算映射表（`diffSegMap`）+ 直接查表
- `DiffSegInfo` 记录每个段在 baseline 中的 `[baseStart, baseEnd]`
- phantom 段 `baseStart === baseEnd`（不占 baseline 空间）
- `rebuildDiffLayer` 通过 baseline 偏移直接定位段，杜绝 phantom 长度污染

### 产出
- 修复方案文档：`docs/rebuildDiffLayer-修复方案.md`
- 待实施：修改 `CodeMirrorDiff.vue`（新增 DiffSegInfo/buildDiffSegMap，重写 rebuildDiffLayer）

### 实施完成（16:47）
- 已修改 `src/components/report-page/CodeMirrorDiff.vue`（rev. A11）：
  1. 新增 `DiffSegInfo` 接口 + `diffSegMap` 变量
  2. 新增 `buildDiffSegMap()` 预计算函数（phantom 段 baseStart===baseEnd）
  3. `ensureEditor()` 中调用 `buildDiffSegMap()`
  4. 重写 `rebuildDiffLayer()`：映射表查表替代长度锁步
- 验证：
  - `vue-tsc --noEmit` 通过；`vite build` 成功
  - 逻辑验证脚本 `scripts/verify-rebuildDiffLayer.js`：真实 diff-match-patch 数据 + 新旧算法对比
  - 旧算法复现 bug（願丢失、mark 右移+1）；新算法全部断言通过（願/。均@25，位置精确）
- 关键学习：**旧算法所有 mark 整体偏移 +1** 是"樂欲聞願"乱序的直接原因；phantom 段长度绝不能计入 baseline 消费预算

## 编辑模式导出应用两层修改（17:15）

### 背景
- 用户需求：编辑模式导出需**应用查看模式对比差异 + 用户编辑**两层修改，导出完整文档
- 现状 bug：编辑模式导出走 `getEditedSegments()`（classifyEdit 稀疏 diff）→ 无编辑时导出**空内容**，有编辑时只含零散变更片段，原始对比差异与正文丢失

### 方案（用户确认：带标记报告 + 用户覆盖原始）
- TXT：直接输出编辑器当前 doc（= 应用两层修改后的最终文档）
- HTML/MD：`mergeLayers` 合成完整文档段——未编辑区域保留原始 add/del/mod 标记，编辑区域只显示用户标记（原始标记隐藏）

### 产出
- 新增 `src/export/mergeLayers.ts`：两层合成算法（placed 投影 + phantom 锚定 + 双游标切片）
  - 核心不变量：`buildDocText(merged) === editText`
  - 关键细节：del phantom 跟随**前**段命运、mod-old phantom 跟随**后**段（mod-new）命运；placed 段按 user 区间边界**切片**输出（粗粒度原始段跨编辑区时正确渲染）
  - ci 重新编号保证两层 id 唯一
- 修改 `src/components/report-page/ExportDialog.vue`：编辑模式分支（TXT=editText；HTML/MD=classifyEdit+mergeLayers）
- 修改 `src/components/report-page/CodeMirrorDiff.vue`（rev. 6-13）：撤销回基线时 `editText` 同步更新（原实现 fresh===baseline 直接 return，导出会读到过期编辑文本）
- 测试：`src/export/__tests__/mergeLayers.spec.ts`（9 例）+ `export-pipeline.spec.ts`（3 例集成），全量 46 通过
- 验证：vue-tsc --noEmit ✓；vite build ✓（注意：dist 清理需用 `rm -rf "D:/.../dist"` 绝对路径，safe-delete shim 会拦截 /d/ 格式；npm run build 偶发 segfault，直接调 .bin 下命令更稳）
