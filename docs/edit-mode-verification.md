# 编辑模式手动验证清单(第一期 A-G 阶段)

> 对应 `docs/编辑模式实现计划.md` §5.2 修订版验证脚本,整理为可勾选清单。
> 适用于阶段 A-G 全部完成后的整体验收。

## 前置

```bash
# 1. 启动后端(注意带 --port,main.py 无 __main__ 入口)
python -m uvicorn src_backend.main:app --host 127.0.0.1 --port 17890

# 2. 启动前端(Vite 代理 /api → 17890 已配置)
cd d:/Desktop/Compare && npm run dev
```

打开 http://localhost:5173。

## 准备夹具

- `sampleA.txt` / `sampleB.txt`:两文件含 1 段删除、1 段新增、1 段修改、若干相同文本
- `markdown.md`:含标题/代码块的 markdown 文档(验证 B4 语法高亮)

## 验证项

- [ ] **1. 基础编辑(阶段 A)**:上传两个 .txt → 完成对比 → 进入编辑模式(Ctrl+E)→ 改几个字 → 看到 4 色高亮(新增=琥珀 `cm-user-add`、删除=紫 `cm-user-del`、修改=暖橙 `cm-user-mod-old/new`)
- [ ] **2. 撤销基线(A2/G1)**:改 A→X → Ctrl+Z 撤销 → 再改 A→Y → 颜色正确且无残留
- [ ] **3. 中文输入(A1)**:连续输入 10 个中文字符 → 无丢字符
- [ ] **4. 删除显示(A5)**:删除一段文字 → 原位置出现紫底删除线 widget(换行显示 ⏎)
- [ ] **5. 修改显示(A6)**:修改一段文字 → 旧值 widget + 新值 mark 并排显示
- [ ] **6. 未编辑区保留原始 diff(A7)**:只改一处 → 其他原始 diff 颜色不变,被触碰区原始颜色消失
- [ ] **7. 撤销到底恢复(A4)**:连续 Ctrl+Z 撤销到底 → 无残留高亮,原始 diff 全部恢复
- [ ] **8. 退出再进入编辑(C3)**:编辑几处 → 退出编辑(Ctrl+E)→ 再进入 → undo 历史保留,之前的编辑颜色仍在
- [ ] **9. 重新对比后编辑(C3 守卫)**:退出编辑 → 上传新文件重新对比 → 再进入编辑 → 显示新文档而非旧文档
- [ ] **10. 搜索(阶段 A9+E1)**:编辑模式 Ctrl+F 搜索编辑后内容 → 命中高亮(琥珀 `cm-search-hl`)→ 位置正确(含 phantom 段前的命中)→ 关闭搜索高亮清除
- [ ] **11. 跳转(E3)**:编辑模式按 J/K → 光标/滚动到对应变更;点击侧边栏变更项 → 同样跳转
- [ ] **12. 还原(C2)**:编辑若干处 → 点击"还原" → 编辑器内容回到原文、颜色全部消失
- [ ] **13. 导出(D1/D2)**:编辑后分别导出 HTML / MD / TXT → HTML 含编辑后内容 + user-mod 颜色;MD/TXT 含编辑后文本,内容不落后于光标(flush)
- [ ] **14. 安全(F1/F2)**:上传含 `<script>alert(1)</script>` 与 `'` 与零宽字符的 .txt → 导出 MD → 在 Typora 打开不弹窗、无 HTML 标签泄漏
- [ ] **15. Markdown 高亮(B4)**:对比两个 .md 文件 → 编辑模式标题/代码块有语法高亮
- [ ] **16. 异常降级(A10)**:在 DevTools 中强制 classify 抛错(如注入非法输入)→ 编辑器不崩、无用户装饰
