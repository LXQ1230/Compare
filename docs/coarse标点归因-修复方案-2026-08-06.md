## 1. 问题背景

用户用 497 级 IDML（497有图.idml → 497导出_WD注入.idml，均 63 万字级）实测对比，
结果中**大量整段删除 + 整段增加**（stats：total 6074 / add 2075 / del 3879 / mod 120），
而两版实词内容几乎完全一致——差异本质是**句读标点注入**（B 版加/移句号）。

用户疑问：为什么会有整段的删除和增加？

## 2. 根因分析

### 2.1 流水线回顾（v7 段落 LCS，2026-08-06 落地）

`max(len(A), len(B)) ≥ 150_000` 字符时走 `diff_texts_para_lcs`：

1. `split_keep` 按 U+2029 切段（保留段尾分隔符）
2. 每段 MD5 → **段落级精确匹配**（内容完全相同的段才 eq）
3. 完整 DP LCS 对齐 → 连续不匹配段组成"替换组"
4. 替换组限长分派：
   - 组总长 ≤ 4096（`_REGION_DMP_MAX`）→ 组内字符级 DMP + 标点归因防线
   - 单对（1 del 段 + 1 add 段）≤ 2048（`_PAIR_DMP_MAX`）→ 组内 DMP
   - **超限 → coarse：整段 DEL + 整段 ADD，跳过标点归因** ← 问题点
5. 全量 merge → 重建校验 → segments

### 2.2 实测数据（497 测试对）

| 指标 | 数值 |
|---|---|
| 段落数 A/B | 1640 / 1638 |
| LCS 对齐 | eq 613 / del 1027 / add 1025 |
| 替换组总数 | 320 |
| fine（字符级 DMP） | 204 组 → mod 120 |
| **coarse（段落级 DEL+ADD）** | **116 组，覆盖 47.7 万字符（≈75% 全文）** |
| coarse 中**实词完全相同**（纯标点差异） | **104/116 组** |

**结论：75% 的文本被整段删加展示，而这 75% 里 90% 的差异只是标点。**

触发链：经文一段约 300–400 字 → 连续 3–4 段就超过 4096 阈值 → 标点修改被段落级展示。
示例（DEL/ADD 内容一字不差，仅"初一日誦"后多一个"。"）：

```
DEL: 中阿含七法品城喻經第三　初一日誦\u2029我聞如是。一時。佛逰舎衛國。…
ADD: 中阿含七法品城喻經第三　初一日誦。\u2029我聞如是。一時。佛逰舎衛國。…
```

### 2.3 为何"整段"语义在此场景不合理

佛经句读场景的修改本质是**标点归因**（加/移/删标点），实词不变。
coarse 分支因性能限长跳过标点归因防线（L1/L2/L3/W），直接段落级展示，
与项目的核心语义承诺（"变更归因于标点而非实词"）冲突。

真重写区域（如整段文字替换）段落级展示是**语义合理**的，应保留。

## 3. 修复方案

### 3.1 核心思路

coarse 分支在输出前先做**实词对齐检测**（`_strip_sep` 比较，纯线性 O(n)，无 DMP）：

- **实词串相同**（wx == wy）→ 用**间隙对齐**（split_by_sep 交错）输出细粒度
  "DEL 标点 + EQ 实词 + ADD 标点"，再叠加 W 空白归因折叠 + 相邻合并。
  → 用户看到的是"此处新增/删除/替换标点"，大部分文本保持黑色不变。
- **实词串不同**（真重写）→ 保持段落级 DEL+ADD（语义合理）。

### 3.2 算法（EQ 合并版间隙对齐）

```python
def _coarse_punct_alignment(x: str, y: str) -> list | None:
    """coarse 组标点归因（2026-08-06 新增）。
    实词串相同 → (del 标点, eq 实词, add 标点) 交错输出；否则 None（保持段落级）。
    输出段数 = O(差异间隙数)，无差异区合并进 EQ 缓冲，段数不爆炸。
    """
    wx, wy = _strip_sep(x), _strip_sep(y)
    if not wx or wx != wy:
        return None                       # 真重写：保持段落级
    gx, cx = split_by_sep(x)              # 复用 L3 的拆分（标点/空白=分隔符）
    gy, cy = split_by_sep(y)
    out: list = []
    eq_buf = ""
    for k in range(len(cx)):
        d, a = gx[k], gy[k]               # 第 k 个实词前的间隙
        if d != a:                        # 间隙不同 → 标点差异
            if eq_buf:
                out.append((0, eq_buf)); eq_buf = ""
            if d: out.append((-1, d))     # A 侧标点删除
            if a: out.append((1, a))      # B 侧标点新增
        else:
            eq_buf += d                   # 间隙相同 → 并入 EQ 缓冲
        eq_buf += cx[k]                   # 实词必然相同 → 并入 EQ 缓冲
    d, a = gx[len(cx)], gy[len(cy)]       # 尾间隙
    if d != a:
        if eq_buf:
            out.append((0, eq_buf)); eq_buf = ""
        if d: out.append((-1, d))
        if a: out.append((1, a))
    else:
        eq_buf += d
    if eq_buf:
        out.append((0, eq_buf))
    return out
```

调用链（coarse 分支内）：

```python
rebuilt = _coarse_punct_alignment(d_text, a_text)
if rebuilt is not None:
    rebuilt = _resolve_whitespace(rebuilt)   # W：DEL 纯空白 + ADD 标点 → 折叠
    rebuilt = _merge_adjacent(rebuilt)       # 相邻同类合并
    raw_parts.extend(rebuilt)
else:
    # 保持现有段落级 DEL+ADD
```

### 3.3 正确性保证

- **数学等价**：间隙对齐按实词对齐把两侧分隔符拆出，DEL 侧 + EQ 侧可重构 A 原文，
  ADD 侧 + EQ 侧可重构 B 原文（与 L3 现有实现同构）。
- **重建校验**：复用流水线尾部 `rebuilt_b == modified` 严格校验 +
  `_strip_ws(rebuilt_a) == _strip_ws(orig)`（A 允许空白差异，W 归因隐藏孤立空白）。
  校验失败仍回退全局 DMP。
- **段落边界**：U+2029 不在 PUNCT/WS 集 → 作为"实词"字符保留在 EQ 中，
  段落合并/拆分（A/B 段落数不同 → 实词串不同）不会误归因，保持段落级展示。
- **样式附着**：输出仍是标准 segments，`_attach_spans` 按游标线性切分，零改动。

### 3.4 性能

- `_strip_sep` / `split_by_sep` 均为单遍线性扫描，47.7 万字符 Python 毫秒级。
- 无新增 DMP 调用（粗粒度区不跑 DMP 是性能前提，保持不变）。
- 输出段数从"整段 6 段"变为"标点级 200± 段"，总量级可接受（见 §5）。

## 4. 边界用例

| # | 场景 | 期望行为 |
|---|---|---|
| 1 | coarse 组实词完全相同（标点注入） | 间隙对齐标点归因，细粒度展示 |
| 2 | coarse 组实词不同（真重写） | 保持段落级 DEL+ADD |
| 3 | A/B 段落数不同（段落合并/拆分） | U+2029 计入实词串 → 不同 → 不重写，段落级 |
| 4 | 间隙两侧均为空（无差异区） | 并入 EQ 缓冲，不输出 DEL/ADD |

| 6 | 间隙两侧不同标点（。→ ，） | DEL+ADD 相邻 → `_build_segments` 合成 mod |
| 7 | 组内仅单对超限（≤2048 分支） | 不受影响（走 fine DMP） |
